01 Sobre mim

Do banco de dados à interface.

Transformo dados em produtos e decisões — unindo engenharia de software, análise de dados e design de interfaces para entregar soluções claras, rápidas e úteis.

Sou desenvolvedor e analista de dados. Trabalho na interseção entre tecnologia e negócio, construindo produtos de dados completos: tratamento e modelagem de grandes volumes com SQL e PySpark, APIs em Node.js conectadas a bancos analíticos como o ClickHouse e interfaces web responsivas em JavaScript e React.

Desenvolvo dashboards e indicadores em Power BI, Chart.js e outras ferramentas de BI, sempre com foco em clareza: a informação certa, no formato certo, para quem precisa decidir. Também automatizo tarefas repetitivas com Python e levo projetos até a publicação com Git e serviços de nuvem.

Sou detalhista, comunicativo e apaixonado por aprender. Gosto de reconhecer padrões, resolver problemas e apresentar resultados de forma simples para quem precisa deles.
